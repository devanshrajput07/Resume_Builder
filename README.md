# 🌟 Resume Builder

Resume Builder is a web application built with the MERN stack that allows users to create professional resumes using different customizable templates. The project integrates an AI-enhanced feature to improve and enrich resume content, making it more impactful and tailored to specific job requirements.

## ✨ Features

- 📝 Build resumes using a variety of resume templates
- 🤖 AI-powered content enhancement to tailor resumes for specific job descriptions and professional summary
- ⚡ Easy-to-use interface for quick resume creation
- 📄 Supports export/download of resumes in popular formats (PDF, DOCX)
- 🔧 Customizable sections and easy editing of resume details

## 🛠️ Technologies Used

- 🗄️ MongoDB for the Database
- 🚀 Express.js for Backend server
- ⚛️ React.js for frontend user interface
- 🟢 Node.js runtime environment
- 🤖 AI integration for content enhancement (e.g., OpenAI)

## 🚀 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/devanshrajput07/Resume_Builder.git
   cd Resume_Builder
   ```

2. Configure environment variables as follows:

   ```
   VITE_BASE_URL=""
   PORT=
   MONGODB_URI=""
   JWT_SECRET=""
   IMAGEKIT_PRIVATE_KEY=""
   OPENAI_API_KEY=""
   OPENAI_BASE_URL=""
   OPENAI_MODEL=""
   ```

3. Navigate to both `server` and `client` directories and install dependencies, then run development servers:

   ```bash
   cd server
   npm install
   npm run dev
   ```

   Open a new terminal window, then:

   ```bash
   cd client
   npm install
   npm run dev
   ```

## 🎯 Usage

- 🖊️ Choose a resume template and fill in your details
- ✍️ Use the AI enhancement feature to improve your resume content
- 📥 Export or download your resume in PDF or DOCX format

This project combines the MERN stack with AI-powered content refinement to provide a seamless, modern, and effective resume building experience that helps users create professional, tailored resumes to increase job interview opportunities.
